# TOEIC MASTER 900+

Responsive static web app starter for a 12-week / 84-day TOEIC study plan.

## Run locally
Open `index.html` in a modern browser. For best results, use a local static server.

## Deploy to Netlify
1. Extract this ZIP.
2. Sign in at https://app.netlify.com/
3. Choose **Add new site → Deploy manually**.
4. Drag the extracted project folder (the folder containing `index.html`) into the deploy area.
5. Netlify will provide a public `*.netlify.app` URL.

## Deploy to Vercel
1. Upload this folder to a GitHub repository.
2. Import the repository at https://vercel.com/new
3. Use the default settings for a static site and deploy.

## Current starter features
- Responsive dark dashboard
- 12-week roadmap overview
- Sample grammar question with instant feedback
- Browser-local progress storage

## Important scope note
This is a starter project, not a completed TOEIC question bank. The full 84-day lesson content, authentic listening audio, expanded practice sets, timed 200-question mock tests, user accounts and cloud synchronization still need to be implemented. Browser-local progress is stored only on the current device/browser. This independent project is not affiliated with ETS.
